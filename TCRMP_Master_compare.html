Initial Summary

This is what Sarah knows upon starting this project in Fall 2025.

There are several “master” copies of the TCRMP fish data, and we don’t know how similar they are, or which is the “most correct”.

  1. “Old Fish”- an Excel file of uncertain provenance. We don’t know how recently it’s been updated, but the R package relies on it. “SMITH LAB TEAM FOLDER/TCRMP/TCRMP_MasterFiles/Old Master Files/Old_Fish_NEEDforCODE.xlsx”
  2. Package .rda files- the R package also relies on these. We also don’t know when they were updated. “/Users/sarahheidmann/UVI Dropbox/SMITH LAB TEAM FOLDER/TCRMP/TCRMP_Administrative/analysis/tcrmp.analysis.zip/data/”
  3. “Master Fish Census”- the Excel file which we had been using as our working “master” before realizing these other copies existed. Sarah had been updating this one with the most recent data but not the others. It is possible that Nicole and maybe Rossie had been updating the other files from this one but we are not sure. “SMITH LAB TEAM FOLDER/TCRMP/TCRMP_MasterFiles/TCRMP_Master_Fish_Census_Mar2025.xlsx”, copied locally on 29 Oct 2025.

The goal of this script is to determine which is the most correct, and consolidate all the data as much as possible. The true “master” will replace #3 above, live in that folder with periodic backups, and the R package will draw directly from there.

Later update: Sarah found some helpful notes from Nicole inside the R package (SMITH LAB TEAM FOLDER/TCRMP/TCRMP_Administrative/analysis/tcrmp.analysis.zip/DataObjectUpdate.Rmd). Nicole found a lot of inconsistencies in the old data but didn’t have time to track down and fix them all. The context she provided is pasted where it is relevant below.

Plain Text Guess at What’s Going On

When Rossie left, the process was that she would take each year’s data in a Excel files, combine it with previous data from a .rda file, and save the updated version of the .rda to the package to work with.

Nicole combined abundance and biomass into a single file, fish. At some point this got changed to fishes, possibly accidentally because of some quirks with using load().

She noticed that the fish .rda file did not match the Dropbox master file from 2003-2021, and for the sake of time and consistency with past reports, she kept the package data in the form of the Old Fish excel file. Each year she would combine Old Fish (2003-2021), Master Fish (2022-2024), and the csv of new data to create her dataset to work with.

Importantly, the .rdas do not include size data as far as I can tell. Only the master file does. Even more reason to use that as our master. Just check the totals match the various other files.

Compare old_fish and master

It looks like there were some merging errors in 2020. There are transects where a species was split across two rows in data entry, and the master contains each of the rows individually as well as them combined. Also, a lot of the species totals don’t match what you get when you sum the size columns.

A lot of these are date issues too, mostly with STX sites 2009-2010 and CRB FSB MGN 2012-2013 when transects for were split across several months into the new year, and were classified as different sample years. Rossie figured out the STX sites and fixed them in OldFish but not the STTJ ones, which I corrected. GBF had some funky transect numbers 2012-2014 that I fixed.

Start with these two files. Make them match so in the future we can use only the master. Use their differences to drill down into errors, changing them in the master, remembering that old fish probably has the accurate numbers.

On second thought, in the interest of time, these mistakes may be an ongoing project. The most important thing is to get the package working so we can do the 2025 data. It may be best to leave it how it is, and/or do it simultaneously.

Are the only differences in sum errors, duplications, and species names? Let’s unduplicate them both and see what happens.

How to Fix It

For the sake of time, I’m going to focus on the differences between Old Fish and the Master. I’m pretty sure that the .rdas are created and overwritten when running DataObjectUpdate.rmd, although I won’t know for sure until we test the process with the 2025 data. We can archive the .rdas just in case.

  • Use the table above to investigate the differences between Old Fish and Master. Datasheets are the source of truth, and in lieu of those, use best judgement, knowing that Old Fish is probably more correct. Make changes manually in the Excel files.

  • Add duplicate species together in the master. Check that all the totals add up the same to make sure I didn’t make a mistake. Also compare these totals to Old Fish and the .rdas.

  • Re-merge the trophic groups using the classifications in the metadata tab. (The old data has inconsistent classification).

  • Add updated biomass calculation coefficients to the metadata tab. Use these to recalculate biomass tab in the master.

  • Change the package to refer to the new master. Replace any use of load() with attach() [and detach()] in the package since it will warn before overwriting (https://www.rdocumentation.org/packages/base/versions/3.6.2/topics/load).
